# Classic Vehicle Restoration Tracker

## Student
Arlo Jolley

## Project Overview
The Classic Vehicle Restoration Tracker is a web application for tracking classic vehicle restoration projects. It will allow users to track parts and costs, record work stages, add photos, and maintain a prioritized list of what needs to be done next.

By the end of Sprint 3, the goal is to have the main interface working with the core tracking features and the project data organized in a useful way.

## Why I Chose This Project
I chose this project because my summer job involves working with classic cars, and I also own some classic vehicles myself. This gives me the opportunity to build something related to an interest I already have while learning more about web development, databases, and organizing data.

## Who This Product Could Help
This product could be useful for people restoring their own classic vehicles as well as restoration shops that need to keep track of multiple projects. It could help organize parts, costs, progress, photos, and what work needs to be done next.
