# CSE_199R
Freshman discovery project(s)

Up to 2 projects in this class each will have its own folder.

The first 1 is a Auto restoration tracker web application/website. Features I am going to try to create are as follows:
Core:
    Create and manage classic vehicle restoration projects
    Track parts needed, ordered, and installed
    Track the cost of parts and restoration work
    Track different stages of restoration work
    Add photos to document the restoration
    Create and manage a prioritized next-actions list
    Store and organize project information using a database
Flex:
    User accounts
    Support for managing multiple vehicles
    Before-and-after photo galleries
    Parts wish lists
    Maintenance record
